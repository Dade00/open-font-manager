# Codice di condotta

Questo progetto accoglie persone con esperienze e competenze diverse. Nelle issue, nelle pull request e negli altri spazi del progetto:

- discuti il codice e le idee senza attaccare le persone;
- usa un linguaggio rispettoso e accetta feedback tecnico motivato;
- non pubblicare dati personali, molestie, minacce, discriminazioni o contenuti sessuali indesiderati;
- evita spam, pressioni sui tempi di risposta e autopromozione fuori contesto.

Il maintainer può modificare o rimuovere contenuti, chiudere discussioni e limitare la partecipazione in proporzione alla violazione. Per segnalare un contenuto usa le funzioni di segnalazione di GitHub; non ripubblicare dati personali per documentare un abuso. Le segnalazioni sono valutate nel contesto disponibile, senza garanzie di presidio continuo.
